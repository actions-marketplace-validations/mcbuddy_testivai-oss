# TestivAI for Java (experimental)

Local-first visual regression capture for playwright-java. Same semantics and
on-disk contract as every TestivAI adapter — one set of baselines, one
report, one approval flow across languages.

Status: full source, not yet published to Maven Central, not yet in CI.
Build with `mvn package`. Docs: [docs/frameworks/java.md](../docs/frameworks/java.md).
